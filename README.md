Rizal in Belgium: A Journey with José Rizal
1. Overview

This project is an interactive, single-page travel brochure about Dr. José Rizal's stay in Belgium from 1890 to 1891, covering Brussels and Ghent. It was prepared for the Chapter 9 activity, "A Journey Through Rizal's Travels." The brochure presents Rizal's experiences, the places he visited, the people who supported him, and the events that shaped El Filibusterismo.

3. Requirements
A modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox or Safari).
An internet connection on first load, to retrieve the Google Fonts (Fraunces, Inter and Caveat).

No installation, build tool or local server is required.

4. Installation and Usage
Download or copy the project folder.
Open index.html in a web browser by double-clicking it or by using File > Open.
5. Site Structure
Section	Content
Hero	Animated title, a route from Paris to Brussels to Ghent, and an interactive passport with dated stamps.
Welcome to Belgium	A brief introduction to the country and its history.
Travel Diary	Six stops shown as horizontal scrolling cards: leaving Paris, the Brussels residence, news from Calamba, the return to Brussels, Ghent, and the publication of El Filibusterismo.
Important Places	A simplified map with selectable locations: the Brussels boarding house, Ghent, and the print shop.
Important People	Profiles of the Jacoby sisters, José Alejandrino, Valentin Ventura, Paciano Rizal, Ferdinand Blumentritt, and José Basa with Sixto Lopez.
Ideas and Observations	An explanation of how the events of 1890 and 1891 influenced the novel.
Timeline	Key dates from January 1890 to September 1891.
Facts and Lessons	Flip cards with additional facts and three lessons drawn from Rizal's journey.
Sources	References for the content presented.
6. Features
Scroll-triggered animations and a reading progress indicator
Horizontal scrolling travel diary with a route indicator
Interactive map and place selector, operable by keyboard
Flip cards that respond to hover, tap or keyboard input
Responsive layout with a mobile navigation menu
Respects the operating system's reduced-motion setting
7. Customization
Content: Locate the section comments in index.html (for example, <!-- PANEL 2: JOURNEY -->) and edit the text that follows them.
Colors and fonts: Modify the CSS custom properties defined in the :root block at the top of the <style> section.
Citations: Replace the placeholder reference titled "Course textbook…" in the Sources section with the full citation of the required textbook.
8. Accuracy and Limitations
Dates and events were verified against the online sources listed in Section 10. Users should confirm them against their course textbook before submission.
The map is schematic and is not drawn to scale.
Historians have not reached agreement on the identity of "Petite Suzanne," the young woman in the Brussels boarding house. The website presents this as an open question.
